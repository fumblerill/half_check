# HalfCheck — Telegram-бот для совместного расчета чеков

**HalfCheck** — это удобный инструмент для разделения общих расходов между друзьями. Больше не нужно вручную считать, кто сколько должен за продукты или ужин. Один человек загружает электронный чек, а остальные просто отмечают свои позиции.

## Основные возможности

- 📁 **Загрузка JSON**: Поддержка JSON-выгрузок чеков (например, из приложений ОФД или ФНС).
- 👥 **Общий доступ**: Несколько пользователей могут одновременно взаимодействовать с одним и тем же чеком.
- ✅ **Интерактивный выбор**: Удобные inline-кнопки для выбора товаров с индикацией количества выбравших.
- ⚖️ **Умный расчет**: Автоматический учет весовых товаров и позиций с количеством > 1. Стоимость делится поровну между всеми, кто отметил позицию.
- 🔒 **Доступ по белому списку**: Возможность ограничить использование бота только для определенного круга лиц через `ALLOWED_USERS`.
- 💰 **Персональный итог**: Мгновенный расчет суммы долга с детализацией по каждой выбранной позиции.
- 🐳 **Docker Ready**: Быстрый деплой через Docker Compose.

## Как это работает

1. **Загрузка**: Один из участников отправляет боту JSON-файл чека.
2. **Выбор**: Все участники нажимают кнопку «Список чеков», выбирают загруженный чек и отмечают товары, которые они купили (или в покупке которых участвовали).
3. **Итог**: Каждый нажимает «💰 Мой итог» и получает детальный список своих трат и финальную сумму.

## Установка и запуск

### Через Docker Compose (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone <url_репозитория>
   cd calculator
   ```

2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```

3. Отредактируйте `.env`, указав ваш токен бота и список разрешенных ID:
   ```env
   TELEGRAM_TOKEN=ваш_токен
   ALLOWED_USERS=12345678,87654321
   ```

4. Запустите проект:
   ```bash
   docker-compose up -d --build
   ```

### Обычный запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите бота:
   ```bash
   python calculator.py
   ```

## Настройка .env

- `TELEGRAM_TOKEN`: Токен вашего бота от [@BotFather](https://t.me/BotFather).
- `ALLOWED_USERS`: Список ID пользователей через запятую, которым разрешен доступ к боту. Если оставить пустым, доступ будет у всех.

## Технологии

- [Python 3.11](https://www.python.org/)
- [python-telegram-bot](https://python-telegram-bot.org/) — основной фреймворк для взаимодействия с Telegram API.
- [Docker](https://www.docker.com/) — для контейнеризации и деплоя.
